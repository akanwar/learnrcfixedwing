# Contributing

Corrections and improvements are very welcome — especially from people who actually build and fly.

## The two-minute version

1. **Fork** this repo and edit the file (everything is plain HTML — no build step).
2. **Test locally** by opening the page in your browser. Print-preview the printables if you touched them.
3. **Open a pull request** that says *what* you changed and *why* — a source link or a photo of the
   measurement that proves the point is gold.

Small fixes (typos, broken links, a wrong number) can also just be an
[issue](https://github.com/akanwar/learnrcfixedwing/issues) if a PR is too much ceremony.

## Ground rules

- **Accuracy over eloquence.** If a claim can't be traced to a primary source (NASA Glenn, MIT OCW,
  UIUC data) or a measurement, say so in the text.
- **Keep the voice:** plain language, numbers over adjectives, honest about uncertainty.
- **No new dependencies.** The site is deliberately framework-free; `designer.js` stays vanilla.
- **Safety content is conservative by default.** PRs that relax safety guidance need strong sourcing.
- By contributing you agree your content contributions are licensed CC BY 4.0 and code contributions MIT,
  matching the repo.
